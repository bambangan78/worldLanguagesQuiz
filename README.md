Couldn't find a quiz with every language on any online quiz website, so i made one


- Language data taken from Glottolog
- Includes extinct languages
- Alternate names accepted else this quiz would be impossible (it probably is anyways), modified as best as possible to avoid accidental entries
    - Accidental acceptances are impossible to avoid sometimes (i.e. both E and U are languages)
- Any families or subfamilies containing the name of a language are blurred
  - Unfortunately similar names are inconsistent and difficult to completely remove
